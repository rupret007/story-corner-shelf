# R10 visual assets

## Deterministic one-bay and first-wall topology

`r10_one_bay_exploded_and_first_wall_topology.svg` is a source-controlled
engineering communication diagram.

- Canvas: 1600 x 1250 SVG units.
- SHA-256: `3bd772110896c264f1cd927933841180dd154d2077b6038d298510256cbf05fb`.
- It records the 254 mm one-bay topology, exact article roles, preassembly
  order, flush-capped log keys, 2.4 mm bayonet motion, 4.0 mm service grip,
  broad bearing lands, and the seven-support / six-bay first-wall topology.
- It deliberately omits wall-hole locations and marks S6 as a replaceable,
  unreleased terminal placeholder.

The SVG is authoritative only for the labeled planning topology. Mesh source,
validated geometry evidence, `ASSEMBLY.md`, and the manifest control exact
part surfaces, saved orientations, and serialization. It is never a drilling
template, print plate, capacity calculation, or installation authorization.
